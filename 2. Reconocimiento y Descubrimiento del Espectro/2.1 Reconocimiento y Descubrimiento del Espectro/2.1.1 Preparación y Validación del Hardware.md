
Para confirmar que Kali Linux reconoce la tarjeta inalámbrica en cada una de sus capas (hardware, controlador e interfaz de red), se utilizan los siguientes comandos:

## 1. Detección a nivel de hardware (Bus físico)
Verifica que el sistema operativo detecta físicamente el dispositivo conectado:

- ### Para adaptadores USB:
```bash
lsusb
```
Busca el nombre del fabricante o chipset (por ejemplo: Realtek, MediaTek/Ralink, Atheros).

- ### Para tarjetas internas (PCI/PCIe):
```bash
lspci -nnk | grep -iA3 net
```
La línea Kernel driver in use: indica qué módulo del núcleo está controlando la tarjeta.

## 2. Detección de la interfaz inalámbrica
Verifica que el núcleo cargó el controlador y creó una interfaz Wi-Fi operativa:

- Comprobar interfaces de red inalámbricas disponibles:
```bash
iw dev
```
o mediante la herramienta tradicional:
```bash
iwconfig
```
Debe figurar una interfaz como `wlan0`, `wlan1` o `wlx[MAC]` con parámetros de radio (frecuencia, ESSID, etc.).

- Identificación rápida con la suite de auditoría:
```bash
sudo airmon-ng
```
Muestra una tabla con la columna `Interface`, el `Chipset` *detectado* y el `Driver` asignado.

## 3. Diagnóstico de bloqueos o errores de firmware
Si el comando lsusb detecta la antena pero no aparece ninguna interfaz `wlan0`:

- Verificar bloqueos por software o hardware (RF-Kill):
```bash
rfkill list
```
Si indica `Soft blocked: yes`, se desbloquea con `sudo rfkill unblock wifi`.

- Revisar mensajes del núcleo en busca de firmware faltante:
```bash
sudo dmesg | grep -iE "wlan|firmware|wifi"
```
Alertará si el sistema detectó el chip pero requiere instalar un paquete de firmware adicional (típico en chipsets Realtek como `rtl8812au` o `rtl8821cu`).
