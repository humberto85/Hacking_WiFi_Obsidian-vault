
### Terminar procesos en conflicto (NetworkManager, wpa_supplicant):
```bash
sudo airmon-ng check kill
```

### Habilitar modo monitor manualmente:

En Linux existen 4 métodos principales, diferenciados por la herramienta y la capa del kernel (nl80211 o la obsoleta wext):

---
#### 1. Con airmon-ng (Automatizado / ==Suite Aircrack-ng==)
Es un script envoltorio que identifica procesos que compiten por el hardware, los neutraliza y renombra la interfaz (frecuentemente a `wlan0mon`):
```bash
sudo airmon-ng start wlan0
```
Para detenerlo:
```bash
sudo airmon-ng stop wlan0mon
```
[[2.1.4 Revertir modo monitor#1. Reversión para el método airmon-ng]] 

---
#### 2. Con `iwconfig` (Método heredado / Wireless Extensions/ ==Ifconfig==)
Utiliza la interfaz antigua wext. La mayoría de controladores modernos lo desaconsejan o ya no lo soportan, pero sigue existiendo en entornos legacy:
```bash
sudo ifconfig wlan0 down
```
```bash
sudo iwconfig wlan0 mode monitor
```
```bash
sudo ifconfig wlan0 up
```
[[2.1.4 Revertir modo monitor#2. Reversión para el método heredado iwconfig]]

---
#### 3. Con `iw` (Estándar moderno `nl80211`)
Modifica la interfaz existente directamente en el subsistema de red actual de Linux:
```bash
sudo ip link set wlan0 down
```
```bash
sudo iw dev wlan0 set type monitor
```
```bash
sudo ip link set wlan0 up
```
[[2.1.4 Revertir modo monitor#3. Reversión para el método `iw` (Interfaz original)]]

---
#### 4. Creando una interfaz virtual con `iw` (Sin alterar la original)
Crea una interfaz de monitoreo dedicada (`mon0`) dejando la interfaz principal intacta:
```bash
sudo iw dev wlan0 interface add mon0 type monitor
```
```bash
sudo ip link set mon0 up
```
Para eliminarla al terminar:
```bash
sudo iw dev mon0 del
```
[[2.1.4 Revertir modo monitor#4. Reversión para el método de interfaz virtual (`mon0`)]]

---

Comprobación del modo activo
Para verificar que la interfaz quedó efectivamente en modo monitor:
```bash
iw dev wlan0 info
```
O con la herramienta clásica:
```bash
iwconfig wlan0
```
