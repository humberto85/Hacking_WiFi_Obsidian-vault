## ¿Cómo funciona el escaneo en modo normal?
### Escaneo Activo (comportamiento por defecto):
Tu antena cambia rápidamente de canal y transmite tramas de sondeo (Probe Requests) al aire diciendo: «¿Qué redes hay por aquí?». Los puntos de acceso responden con un Probe Response.

Desventaja en auditoría: Generas tráfico radioeléctrico rastreable (tu MAC real o aleatoria queda registrada en los logs de los APs cercanos).

### Escaneo Pasivo (escucha sin transmitir):
Tu tarjeta sintoniza cada canal durante una fracción de segundo y únicamente escucha las tramas de baliza (Beacon frames) que los routers emiten de forma periódica (aproximadamente cada 100 ms). No transmites ningún paquete.

## Comandos para escanear en modo normal
### 1. Escaneo estrictamente pasivo con iw (==Recomendado==)
El subsistema de red moderno de Linux permite forzar el flag pasivo sin levantar modo monitor:
```bash
sudo iw dev wlan0 scan passive
```
Para filtrar la salida y ver solo los parámetros esenciales (BSSID, SSID, señal y canal):

```bash
sudo iw dev wlan0 scan passive | grep -E "BSS|SSID:|signal:|primary channel"
```

---

## 2. Escaneo estándar con nmcli (==Rápido pero activo==)
La interfaz de línea de comandos de NetworkManager realiza un barrido activo rápido:
```bash
nmcli dev wifi list
```
- Muestra una tabla con SSID, BSSID, modo, canal, tasa de transferencia, nivel de señal (RSSI) y tipo de cifrado.

- Para forzar una actualización de la lista:
```bash
nmcli dev wifi rescan
nmcli dev wifi list
```

---

## 3. Escaneo tradicional con iwlist (Generalmente activo)

```bash
sudo iwlist wlan0 scan | grep -E "Address:|ESSID:|Channel:|Quality"
```
